Website Analyzer

Paste a URL to inspect SEO, performance, and structure.

What you get

  • HTTP status, response time, content size, server
  • Page title, meta description, language, charset
  • Heading structure (H1–H6), links, images, forms
  • SEO checks: HTTPS, canonical, viewport, favicon
  • Word count and top keywords

Built with Spring Boot · Deployable on Render or Railway via Docker
